For this Project I wanted to make an rpg game engine where you can create a text based rpg style game. I started by creating all of the main class and then moved on to creating the Event class this just creates an event that the story can read and turns it into a string. Then the Character and Combat class I had previosuly created in my own rpg fighting game and the enemy is similar to the character class with just a little difference to where the user doesn't pick the action. I then added a save file with json then used load about the same way. For this I made all of the code at one point in time. The main file also handles save, load, and creating an event.
